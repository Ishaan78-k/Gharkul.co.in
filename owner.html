Owner login

Sign in to add properties, photos and announcements.

Two-step verification

First time: open Google Authenticator or Microsoft Authenticator on your phone, choose Add account → Enter a setup key, type this key (time-based), then enter the 6-digit code it shows.

Open in authenticator app

Enter the 6-digit code from your authenticator app, or a recovery code.

Save your recovery codes

Each code works once if you lose your phone. They are shown only now. Write them down or store them in a password manager.
